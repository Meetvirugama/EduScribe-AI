# Troubleshooting Guide

This document outlines common errors you might encounter while developing or deploying EduScribe AI, and how to resolve them.

## 1. yt-dlp "Sign in to confirm you're not a bot"
**Symptom**: When submitting a YouTube URL, the process immediately fails with a `youtube_bot_protection` error in the dashboard.
**Cause**: YouTube frequently updates its anti-bot algorithms, temporarily blocking `yt-dlp` requests from datacenters or unknown IPs.
**Fix**: 
- Ensure you are running the absolute latest version of `yt-dlp`. 
- If the issue persists, the backend supports passing browser cookies to bypass the block. See `youtube.py` for instructions on mounting a `cookies.txt` file into the container.

## 2. Neon PostgreSQL Connection Drops
**Symptom**: Background tasks crash with `asyncpg.exceptions.ConnectionDoesNotExistError` or `ConnectionResetError` after long processing times.
**Cause**: Serverless databases like Neon often drop idle connections aggressively. If the Whisper AI model takes 3 minutes to run, the database connection might close in the meantime.
**Fix**: The backend implements retry logic and SQLAlchemy pool recycling, but if you still see this, try clicking "Retry" in the dashboard, or switch to a persistent local PostgreSQL instance.

## 3. OOM (Out of Memory) Killer
**Symptom**: The Docker container abruptly stops with Exit Code 137.
**Cause**: Loading Whisper and PaddleOCR simultaneously requires at least 4GB to 6GB of free RAM.
**Fix**: Increase the memory limit in Docker Desktop settings to at least 8GB.

## 4. ESLint react-hooks/exhaustive-deps Warnings
**Symptom**: `npm run lint` throws warnings about missing dependencies in `useEffect`.
**Cause**: State update functions (like `setVideos`) or API fetch wrappers might not be wrapped in `useCallback`.
**Fix**: Ensure all functions called inside a `useEffect` are memoized using `useCallback`, or disable the warning specifically for polling intervals.

## 5. Upcoming: Image Generation Failures
**Symptom**: The final PDF lacks AI generated simple images, or the dashboard shows an "Image Gen Failed" status.
**Cause**: Likely an invalid `IMAGE_GEN_API_KEY` or a timeout from the external generation service.
**Fix**: Check your API quotas and ensure the prompt generated by the Concept Extractor isn't hitting any safety filters.
